### 音乐

音乐是一个很神奇的东西，带上耳机则是更妙不可言的极致享受。当你沉浸在音乐中，整个世界都与你无关；当你与音乐发生共鸣，整个世界好像都在你手中。

> 不带耳机，音乐是世界的一部分；带上耳机，音乐就是整个世界。

喜欢听什么音乐？
- 欧美流行（AlanWalker, ImagineDragons, OneRepublic等）
- 日语流行（虽然本人二次元浓度几乎为零，但音乐好听就是好听）
- 有的中文歌也听，但现在的华语乐坛……难说

当你听音乐听多了就会发现，歌品的变化是很快的，也许过了一周不到你就会喜欢上其他的曲风。

## 关于网站

### 这个小站是怎么建成的？

我曾经考虑过搭建一个属于自己的个人网站，但只会 python 和 C++ 的我无能为力。而一些现成的建站工具的成品始终不尽人意。

于是，我开始学习 HTML 和 CSS，尝试自己写网站。但是太丑了，我就这样陷在了反复的美化陷阱中，根本没时间写内容。

后来在B站上无意看到了对astro的介绍，我就决定试试。后来，就有了现在这个网站。
